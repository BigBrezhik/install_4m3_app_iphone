# Установка 4m3 на iPhone — подробный гайд по шагам

Этот файл объясняет, как поставить приложение 4m3 (радио + ТВ) на iPhone без App Store.
Написано просто, по шагам. Если читаешь первый раз — иди по порядку.

---

## Что понадобится заранее

1. **Сам файл приложения `4m3app.ipa`.**
   Скачай его на компьютере здесь https://4m3.ru/app/4m3app.ipa
2. **Компьютер: Windows 10 или новее, или Mac** (macOS 11 и новее).
3. **Кабель** для подключения iPhone к компьютеру (коннектор Lightning).
4. **Версию iOS на твоём iPhone.** Узнать: Настройки → Основные → Об этом устройстве → строка «Версия ПО».
   Запиши её — по ней выбираем способ установки ниже.

> Если телефон уже с установленным TrollStore — перепрыгни сразу к разделу
> **«Как закинуть 4m3 в TrollStore»**.

---

## Какой способ подходит твоей iOS

| Версия iOS | Способ |
|---|---|
| 15.8.7, 15.8.8 | **TrollRestore** (способ №1, Windows или Mac) |
| 16.7 RC (20H18) | **TrollRestore** (способ №1) |
| 17.0 | **TrollRestore** (способ №1) |
| 14.0 – 16.6.1 | **TrollInstallerX** (способ №2) |
| 15.0 – 15.4.1 | **TrollHelperOTA** (способ №3) |
| 17.0.1 и новее, 18, 19, 20, 26 | TrollStore НЕ работает → **способы №4–6** |

---

## Способ №1. TrollRestore (iOS 15.8.7 / 15.8.8 / 16.7 RC / 17.0)

Делается через программу на компьютере (Windows или Mac). Один раз — и подпись больше никогда не истекает.

1. **Выключи «Найти iPhone»** на телефоне:
   Настройки → (твоё имя) → iCloud → Найти iPhone → выключи тумблер.
   (Спросит пароль от Apple ID — введи. Потом можно включить обратно.)
2. **Подготовь компьютер:**
   - **Windows:** поставь iTunes (без него программа не работает):
     https://www.apple.com/itunes/download/win64
     Скачай, запусти установщик, дождись окончания.
   - **Mac:** ничего ставить не надо — подойдёт штатное приложение «Finder».
3. **Скачай программу TrollRestore:**
   https://github.com/JJTech0130/TrollRestore/releases
   - **Windows** → файл **`TrollRestore.exe`**;
   - **Mac на чипе Apple (M1/M2/M3/M4)** → файл **`TrollRestore_macOS_arm64.zip`**;
   - **Mac на чипе Intel** → файл **`TrollRestore_macOS_amd64.zip`**.
   Распакуй архив (на Mac — двойной клик по .zip).
4. **Подключи iPhone к компьютеру кабелем.**
   На телефоне появится окно «Доверять этому компьютеру?» — нажми **«Доверять»**
   и введи пароль телефона.
5. **Запусти TrollRestore:**
   - **Windows:** двойной клик по `TrollRestore.exe`;
   - **Mac:** двойной клик по файлу TrollRestore в распакованной папке.
     (Mac может спросить разрешение — тогда: Правый клик → Открыть → Открыть.
     Если пишет «невозможно проверить разработчика» — Параметры системы →
     Конфиденциальность и безопасность → всё равно открыть.)
6. Программа спросит имя приложения, которое заменим. Напиши **`Tips`** и нажми Enter.
   (Это системное приложение «Советы». Оно превратится в установщик TrollStore.)
7. **Жди.** Телефон сам перезагрузится (на экране будет полоса прогресса). Не трогай кабель.
8. **Открой на телефоне приложение «Советы»** (его иконка осталась, но это теперь TrollHelper).
9. Нажми кнопку **«Install TrollStore»**.
10. Телефон снова «перезагрузится сам» (respring). На экране появится приложение **TrollStore**.

Готово. Теперь иди к разделу **«Как закинуть 4m3 в TrollStore»**.

## Способ №2. TrollInstallerX (iOS 14.0 – 16.6.1)

Тоже через компьютер, но чуть другим путём: сначала ставим сам установщик через программу Sideloadly.

1. **Скачай Sideloadly** (программа для подписи приложений): https://sideloadly.io
   Нажми Download — программа есть **и для Windows, и для Mac** (выбери свою систему).
   Распакуй архив и запусти:
   - **Windows:** двойной клик по `sideloadly.exe` (если Windows ругается —
     «Подробнее» → «Выполнить в любом случае»);
   - **Mac:** двойной клик по `Sideloadly.app` (если Mac ругается —
     Правый клик → Открыть → Открыть).
2. **Скачай TrollInstallerX:** https://github.com/alfiecg24/TrollInstallerX/releases
   Скачай файл **`TrollInstallerX.ipa`**.
3. **Подключи iPhone к компьютеру**, нажми «Доверять», введи пароль.
4. В Sideloadly:
   - в поле «IPA» выбери скачанный `TrollInstallerX.ipa`;
   - в поле «Apple ID» впиши свой Apple ID и пароль (обычная бесплатная почта @icloud или другая — сойдёт);
   - нажми кнопку **Start**.
   Программа подпишет и поставит TrollInstallerX на телефон.
5. **Открой на телефоне приложение TrollInstallerX.**
6. Нажми кнопку **«Install TrollStore»** и подожди.
7. Телефон перезагрузится. Появится **TrollStore**.

Теперь к разделу **«Как закинуть 4m3 в TrollStore»**.

## Способ №3. TrollHelperOTA (iOS 15.0 – 15.4.1)

Вообще без компьютера — всё делается в Safari на самом телефоне.

1. Открой на iPhone в браузере **Safari** страницу установки:
   https://ios.cfw.guide/installing-trollstore/
   (На ней есть кнопки-вкладки по версиям — выбери свою и нажми ссылку «TrollHelperOTA».)
   Откроется установочная страница.
2. Нажми кнопку **Install** на той странице.
3. Safari спросит разрешение — соглашайся.
4. На экране появится приложение **TrollHelper**.
5. Открой его → нажми **«Install TrollStore»**.
6. Телефон «перезагрузится сам». Появится **TrollStore**.

Теперь к разделу **«Как закинуть 4m3 в TrollStore»**.

---

## Как закинуть 4m3 в TrollStore

1. Скопируй файл `4m3app.ipa` на iPhone любым способом:
   - через AirDrop (с Mac или iPhone), или
   - через iCloud Drive / «Файлы», или
   - скинь через проводник iTunes (компьютер → «Файлы» → TrollStore), или
   - скачай отсюда https://4m3.ru/app/4m3app.ipa
2. Открой приложение **TrollStore**.
3. Нажми **«+»** вверху справа (или «Install»).
4. Выбери файл `4m3app.ipa` из списка.
5. Подожди несколько секунд — приложение установится и появится на рабочем столе.

Готово! Подпись бессрочная, ничего переподписывать не надо.

## Способ №4. Sideloadly без TrollStore (iOS 17.0.1+, 18, 26)

Если TrollStore не работает на твоей версии iOS — остаётся обычная подпись.
Работает, но: приложение живёт **7 дней**, потом надо переподписывать заново
(подключить телефон к компьютеру и повторить). И лимит — максимум **3 приложения**.

1. Скачай Sideloadly (Windows или Mac): https://sideloadly.io
2. Скачай `4m3app.ipa` (ссылка в начале файла).
3. Подключи iPhone, нажми «Доверять», введи пароль.
4. В Sideloadly выбери `4m3app.ipa`, впиши Apple ID и пароль, нажми **Start**.
5. Если iOS 16 или новее — включи **«Режим разработчика»**:
   Настройки → Конфиденциальность и безопасность → Режим разработчика → ВКЛ → перезагрузка.
   (Пункт появится после первой подписи через Sideloadly.)
6. В Настройках iPhone: **Основные → VPN и управление устройством** → там твой Apple ID →
   нажми **«Доверить»**.
7. Открой 4m3 — работает.
8. Через 7 дней: снова подключи к компьютеру, запусти Sideloadly, нажми **Start** (переподпись).

## Способ №5. SideStore + LiveContainer (iOS 17.0.1+, 18, 26, без компьютера потом)

То же самое, что способ №4, но переподпись происходит **сама по Wi-Fi**,
а LiveContainer позволяет обойти лимит в 3 приложения.

1. Один раз на компьютере: скачай **Dadoum/Sideloader** (https://github.com/Dadoum/Sideloader,
   есть Windows, Mac и Linux) и файл **SideStore** (https://sidestore.io).
   Установи SideStore на телефон по инструкции с сайта.
2. Подключи телефон к тому же Wi-Fi, что и компьютер.
3. Открой SideStore — он сам будет продлевать подпись.
4. Для обхода лимита 3 приложений поставь **LiveContainer**:
   https://github.com/khanhduytran0/LiveContainer
   (внутри него можно запускать много приложений под одной подписью).

## Способ №6. Платный Apple Developer (iOS любая, на год, без лимитов)

Самый надёжный: подпись на целый год, до 100 устройств, без лимита на количество приложений.
Но стоит **99 $ в год**.

1. Купи разработческий аккаунт: https://developer.apple.com/programs/
2. На компьютере подпиши `4m3app.ipa` своим сертификатом через **Feather**
   (https://github.com/khcrysalis/Feather) или E-Sign.
3. Установи подписанный файл на телефон. Переподпись — раз в год.

## Что делать, если что-то не работает

- **TrollStore не появляется после «Install»** → повтори способ №1 с шага 5.
  Убедись, что «Найти iPhone» выключен.
- **Программа на компьютере не запускается** →
  - **Windows:** поставь iTunes (ссылка в способе №1) или запусти файл «от имени администратора».
  - **Mac:** Правый клик по файлу → Открыть → Открыть. Или Параметры системы →
    Конфиденциальность и безопасность → «всё равно открыть».
- **Sideloadly пишет ошибку / не видит телефон** → поменяй кабель (нужен оригинальный или качественный),
  обнови iTunes, перезапусти компьютер и телефон.
- **Приложение просит «Доверить разработчику»** → Настройки → Основные → VPN и управление устройством → Доверить.
- **Приложение «умерло» через 7 дней** → переподпиши через Sideloadly (способ №4) или поставь SideStore (№5).
- **iOS 17.0.1 и новее — тут нет способа с бессрочной подписью.**
  Это ограничение Apple, не обходится без джейлбрейка. Выбирай №4, №5 или №6.
